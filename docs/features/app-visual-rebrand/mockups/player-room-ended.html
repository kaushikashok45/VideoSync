State depicted: Player, terminal "room ended" state (PD-002). The room-code chip is replaced with a de-emphasized Room ended label rather than shown disabled, because there is nothing left to confirm; the invite action is removed entirely, not disabled, since inviting someone into a room that no longer exists is not a degraded action, it is a false one. The reaction tray and capsule are not shown here — playback has stopped and there is nothing left to react to or control, which is a player-body concern this feature does not redesign, only the chrome's response to it.
